# SnoozeTax Release & Submission Guide

This guide outlines the steps required to package and submit SnoozeTax to the Apple App Store and Google Play Store using Expo Application Services (EAS).

## Prerequisites

1.  **Expo Account**: You must have an account at [expo.dev](https://expo.dev).
2.  **EAS CLI**: Install the CLI globally: `npm install -g eas-cli`.
3.  **Login**: Run `eas login` in your terminal.
4.  **Developer Accounts**:
    *   Apple Developer Program membership ($99/year).
    *   Google Play Console developer account ($25 one-time).

## 1. Project Initialization

Run the following command to link your local project to the EAS servers:

```bash
eas project:init
```

## 2. Production Builds

Generate the binaries for both platforms:

### Android (AAB for Play Store)
```bash
eas build --platform android --profile production
```

### iOS (IPA for App Store)
```bash
eas build --platform ios --profile production
```

*Note: EAS will guide you through generating or uploading credentials (Keystore for Android, Distribution Certificate and Provisioning Profile for iOS).*

## 3. App Store Submission

Once the builds are complete, you can submit them to the stores directly from the CLI.

### Google Play Store
```bash
eas submit --platform android --profile production
```

### Apple App Store (TestFlight)
```bash
eas submit --platform ios --profile production
```

## 4. Internal Testing (Optional but Recommended)

Before submitting for public review, you can generate a "preview" build for internal testing.

### Android APK (Shareable link)
```bash
eas build --platform android --profile preview
```

## Checklist for Store Review

- [ ] **Privacy Policy**: Ensure you have a URL for your privacy policy (required by both stores).
- [ ] **App Store Screenshots**: Capture screenshots of the Alarm list, Wallet, and Wood Block Puzzle.
- [ ] **App Description**: Highlight the "Accountability" and "Anti-Snooze" features.
- [ ] **Contact Info**: Provide support contact information.
- [ ] **Demo Account**: If the app required login (which SnoozeTax currently does not), you would provide credentials. Since it uses local storage, just note that no account is needed for initial review.
